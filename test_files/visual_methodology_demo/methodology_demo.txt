ДЕМОНСТРАЦИОННАЯ МЕТОДИКА: ВЫБОР ПЕЙЗАЖЕЙ ПО ИЗОБРАЖЕНИЯМ
=========================================================

Назначение
----------
Это вымышленный технический пример для проверки загрузки изображений,
вопросов с одиночным и множественным выбором, сохранения ответов, подсчёта
баллов и экспорта в DOCX.
Это НЕ валидированная психологическая методика. Её нельзя использовать для
оценки учеников; она не имеет психологической интерпретации или диагностического
значения.

Создайте в приложении отдельную временную методику
-------------------------------------------------
Код: DEMO_LANDSCAPE_01
Название: ТОЛЬКО ДЕМО — выбор пейзажа по изображению
Режим: Задания с выбором вариантов

Описание:
Техническая демонстрация заданий с изображениями и обработки ответов.
Не является психологической оценкой.

Инструкция ученику:
Это только демонстрация интерфейса тестирования. Здесь нет правильных или
неправильных ответов. Ваш выбор не будет интерпретироваться как психологический
результат.

Задание 1 — множественный выбор
-------------------------------
Формулировка:
Для демонстрации интерфейса выберите два или более пейзажа, которые вам хотелось
бы рассмотреть внимательнее.

Режим выбора: Выбрать несколько вариантов

Добавьте четыре варианта ответа и прикрепите к каждому указанное изображение:
1. Лесная тропа              -> 01_forest_path.jpg      -> балл 1
2. Горное озеро              -> 02_mountain_lake.jpg    -> балл 1
3. Поле подсолнухов на закате -> 03_sunflower_sunset.jpg -> балл 1
4. Морское побережье         -> 04_coastal_beach.jpg    -> балл 1

Задание 2 — одиночный выбор
---------------------------
Формулировка:
Представьте, что вы выбираете пейзаж для открытки. Какой из них вы бы выбрали?

Режим выбора: Выбрать один вариант

Добавьте те же четыре варианта ответа и прикрепите соответствующие изображения:
1. Лесная тропа              -> 01_forest_path.jpg      -> балл 0
2. Горное озеро              -> 02_mountain_lake.jpg    -> балл 0
3. Поле подсолнухов на закате -> 03_sunflower_sunset.jpg -> балл 0
4. Морское побережье         -> 04_coastal_beach.jpg    -> балл 0

Порядок проверки
----------------
1. Убедитесь, что в настройках приложения указана база Testdb, а не SchoolTest.
2. Сохраните это как новую методику; не редактируйте уже существующие методики.
3. Откройте методику повторно и убедитесь, что задания, варианты и изображения
   сохранились.
4. Пройдите её под тестовой учётной записью ученика в Testdb.
5. Проверьте сохранённые ответы и экспортируйте отчёт DOCX.
6. После технической проверки удалите или архивируйте временную методику и
   тестовую сессию в Testdb штатными средствами приложения.

Для этой демонстрации не нужно добавлять шкалы. Баллы в задании 1 проверяют
только суммирование баллов нескольких выбранных вариантов. Это не измерение.
