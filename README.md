# School Psychology Testing App

## Описание проекта

Это desktop-приложение для школьной психологической диагностики. Оно позволяет:
- выполнять вход в систему по ролям;
- управлять учениками, классами и школой;
- запускать психологические тесты;
- сохранять результаты и историю прохождений;
- использовать личный кабинет для учащихся;
- вести базовую административную панель для психолога и администратора.

## Структура проекта

- `main.py` — точка входа приложения.
- `config/` — настройки приложения и конфигурация окружения.
- `src/gui/` — графический интерфейс на PySide6.
- `src/services/` — бизнес-логика и взаимодействие с БД.
- `src/models/` — модели данных.
- `src/api/` — слой API для дальнейшего расширения.
- `src/core/` — базовые сервисы и ядро безопасности.
- `database/` — инфраструктура работы с базой данных.
- `tests/` — тесты проекта.
- `backups/` — резервные копии проекта и дампы SQL.
- `logs/` — логи работы приложения.

## Требования

- Python 3.11+
- PostgreSQL 14+
- PySide6
- FastAPI (для API-слоя)
- psycopg2
- python-dotenv

## Подготовка окружения

1. Установите зависимости:

   python -m pip install -r requirements.txt

2. Проверьте, что у вас существует файл `.env` в корне проекта.
3. Для базы данных используйте имя `SchoolTest` в соответствии с вашей реальной PostgreSQL БД.

Пример `.env`:

```dotenv
DB_HOST=localhost
DB_PORT=5432
DB_NAME=SchoolTest
DB_USER=school_psych_app
DB_PASSWORD=your_password
DB_SCHEMA=psychology
SECRET_KEY=your_secret_key
ALGORITHM=HS256
```

## Запуск приложения

Запуск GUI:

```bash
python main.py
```

## Проверка состояния БД при старте

При запуске проект автоматически выполняет проверку подключения к PostgreSQL.
Если соединение недоступно, программа выводит понятное сообщение и завершает запуск без ломки текущего GUI-процесса.

## Тестирование

Запуск полного набора тестов:

```bash
python -m pytest -q
```

## Резервная копия проекта

Архив проекта хранится в папке `backups/` в формате ZIP, который подходит для открытия в WinRAR и последующего восстановления.

## Важные замечания

- не переписывайте уже рабочий GUI без необходимости;
- добавляйте новые функции пошагово в сервисы и слои;
- API является отдельным расширением и не должен ломать текущий GUI-поток;
- при изменении окружения обязательно обновляйте `.env` и проверяйте соединение с БД.
