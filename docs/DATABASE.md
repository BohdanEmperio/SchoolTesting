# Database guide

## Основная БД

Текущая рабочая база проекта: `SchoolTest`.

## Схема

Основная схема: `psychology`.

## Ключевые сущности

- `users` — пользователи с ролями admin / psychologist / student
- `students` — данные учащихся
- `classes` — классы и учебные группы
- `psychological_tests` — тесты
- `test_sessions` — сессии прохождения
- `test_results` — итоговые результаты
- `notifications` — уведомления

## Важные правила

- Используйте `.env` для конфигурации соединения.
- Не меняйте схему без проверки совместимости с текущими сервисами.
- При добавлении новых таблиц обязательно сверяйте их с GUI и сервисами.

## Методики с вариантами и рисунками

Режим методики хранится в `psychological_tests.config.test_mode`: старые записи без
этого параметра продолжают считаться опросниками «Да / Нет». Варианты ответов и
выбранные учеником пункты хранятся в JSONB-полях существующих таблиц.

Файлы рисунков хранятся в `test_question_media` как `BYTEA`; поэтому они доступны
ученикам с разных компьютеров и попадают в резервные копии схемы `psychology`.
Поддерживаются PNG и JPEG. Для создания таблицы и сохранения истории вопросов
применяется SQL-миграция `database/migrations/005_visual_methodology.sql`.

Перед запуском миграции создайте резервную копию и проверьте её восстановлением в
отдельной базе. Сначала применяйте миграцию к тестовой базе; рабочую базу обновляйте
только после проверки редактора, прохождения методики и DOCX-отчётов.

```powershell
& "C:\Program Files\PostgreSQL\18\bin\psql.exe" `
  -X -h localhost -p 5432 -U postgres -d Testdb `
  -W -v ON_ERROR_STOP=1 `
  -f "C:\полный\путь\к\проекту\database\migrations\005_visual_methodology.sql"
```
