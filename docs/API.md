# API documentation

## Назначение

API в проекте является отдельным слоем интеграции и не заменяет текущий GUI.

## Основные маршруты

- `/api/auth` — аутентификация и вход.
- `/api/students` — работа со списком и профилями учеников.
- `/api/tests` — работа с методиками и диагностическими тестами.
- `/api/admin` — административные операции.

## Проверка доступности

```bash
curl http://127.0.0.1:8000/health
```

## Важное правило

GUI остаётся основным пользовательским интерфейсом. API добавляется как расширение, чтобы в будущем можно было подключать внешние системы без ломки текущего интерфейса.
